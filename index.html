Cloud Sync Setup (free)

Connect a free Firebase database once. After that, every story, project, credential and organization you add shows up for all visitors within a second, with no re-uploading of this HTML file.

1. Create the database
Go to console.firebase.google.com → Add project (turn Analytics off) → Build → Firestore Database → Create database (production mode, pick the closest region).
2. Turn on owner login
Build → Authentication → Get started → Google → Enable. Then Settings → Authorized domains → Add domain and add your site's domain (for GitHub Pages: yourname.github.io).
3. Paste the security rules
Firestore Database → Rules: replace everything with the rules below and click Publish. They let everyone read the site, but only can change it. Appointments are private.
4. Connect this site
Project settings (gear icon) → Your apps → Web (</>) → register an app → copy the firebaseConfig block and paste it here.

Save & Connect turns sync on for this browser so you can test it. To turn it on for every visitor, click Copy line for index.html, paste it over const FIREBASE_CONFIG = null; near the top of the script, and upload the file once. Your existing content uploads automatically the first time you sign in.
